## 📝 RÉSUMÉ DU PROJET

### French (Résumé)
Ce projet de fin d’études porte sur la conception et le développement d’une plateforme numérique multi-support dédiée à la découverte de produits et de boutiques locales. La plateforme se décline en trois composantes principales : une application web destinée aux consommateurs, une application mobile native pour une accessibilité optimale, et un tableau de bord administrateur pour la gestion globale de la plateforme. L’innovation centrale du projet réside dans l’intégration d’un moteur de recherche sémantique basé sur des embeddings vectoriels stockés dans une base de données PostgreSQL via l’extension pgvector, permettant une découverte contextuelle et intelligente dépassant les limites de recherche par mots-clés classique. La plateforme intègre également un système de contenu court de type reels, une messagerie en temps réel et un contrôle d’accès basé sur les rôles. L’ensemble est développé avec Next.js, React Native et Django(Python), déployé sur Vercel et adossé à l’infrastructure Supabase.

### Keywords (FR)
Mots clés: Découverte, Recherche sémantique, Marketplace, Application Mobile, Tableau de bord, React Native, Next.js, Django, Supabase, pgvector, Vercel.

### English (Abstract)
The current research concerns the development of a multi-channel digital product for product discovery and searching for nearby stores. This platform contains three main parts: web app, a native mobile application, and admin dashboard for overall platform management. The innovative aspect here concerns using a semantic search technology based on vector embeddings  stored in the PostgreSQL database with pgvector plugin. In other words, the idea is that such kind of search technology makes it possible to use intelligent discovery and find products beyond classical keyword-based search functionality. The current project includes some additional features like a system of reels, messaging, and roles. All technologies used in this project are Next.js, React Native, Django(Python) and deployment is done through Vercel. Also, all services are based on Supabase.

### Keywords (EN)
Key-words: Discovery, Semantic Search, Marketplace, Mobile Application, Dashboard, React Native, Next.js, Django, Supabase, pgvector, Vercel.
